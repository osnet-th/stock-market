# #132 기업 리포트 작성 중 종목 변경 시 S-RIM 입력 초기화

- url: https://github.com/osnet-th/stock-market/issues/132
- state: OPEN
- saved: 2026-09-29 13:45

## 본문

## 작업 내용
- 새 기업 리포트 작성 중 1단계로 돌아가 다른 종목을 고르면, 이전 종목의 S-RIM 입력(지배주주지분·유통주식수·기준일·요구수익률·연도 행)과 채권 기준수익률 선택 상태가 그대로 남는다.
- 종목이 바뀌면 S-RIM 입력과 채권 기준수익률 선택 상태를 초기화한다.
- 특히 원화 종목에서 적용한 채권 기준수익률이 외화(USD) 종목 S-RIM에 남지 않게 한다. 현재는 경고 문구만 표시한다.

## 완료 조건
- 다른 종목으로 바꾸면 S-RIM 단계에 이전 종목의 입력값과 적용 근거가 남지 않는다.
- 같은 종목을 다시 고르거나 수정·재개 모드에서는 기존 입력이 유지된다.
- 저장된 리포트의 S-RIM 데이터와 계산식은 바뀌지 않는다.

## 배경
- #131 리뷰에서 확인했다. 기존 위저드는 종목을 바꿔도 S-RIM 입력을 초기화하지 않는다.
