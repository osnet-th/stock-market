## 본문

## 작업 내용
- 자산 등록·수정 시 금융기관(은행·증권사 등)을 입력하는 칸 추가
- 보유 자산 목록에 금융기관 표시
- 금융기관별 평가액 합계와 비중 표시, 미입력 자산은 "미지정"으로 묶음

## 완료 조건
- 모든 자산군 등록·수정에서 금융기관을 입력·수정할 수 있다
- 금융기관별 합계가 평가액 기준으로 보인다
- 기존 자산은 금융기관이 비어 있는 상태로 그대로 동작한다

## 범위 밖
- 금융기관 목록 관리, 은행 API 연동, 계좌번호 저장
