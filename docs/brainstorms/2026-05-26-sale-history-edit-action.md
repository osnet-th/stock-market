# 매도 이력 수정 진입점 보완

## 문제

매도 이력 사후 수정 기능은 상세 모달 안에 구현되어 있지만, 매도 이력 목록 화면에는 명시적인 `수정` 버튼이 없다.

사용자는 목록 행을 클릭해야 상세 모달이 열리고, 그 안에서 다시 수정 모드로 들어갈 수 있다는 사실을 화면만 보고 알기 어렵다. 특히 기존 매도 이력을 정정하려는 사용자는 "수정 버튼이 없다"고 인식할 수 있다.

## 목표

- 매도 이력 목록에서 기존 매도 이력을 바로 수정할 수 있는 진입점을 제공한다.
- 기존 상세 모달과 편집 로직은 재사용한다.
- 매도 이력 계산, 저장 API, 엔티티, 정산 금액 로직은 변경하지 않는다.

## 요구사항

- 매도 이력 각 행에 `수정` 액션을 명시적으로 표시한다.
- `수정` 클릭 시 기존 매도 이력 수정 폼이 바로 열린다.
- 행 클릭으로 상세 모달을 여는 기존 동작은 유지한다.
- 사용자가 상세만 보고 싶을 때를 위해 `상세` 액션도 함께 표시한다.
- 버튼 클릭은 행 클릭 이벤트와 충돌하지 않아야 한다.

## 결정

- 목록 행 내부 우측 영역에 `수정`/`상세` 텍스트 버튼을 추가한다.
- `수정`은 기존 `createSaleEditForm(history)`를 사용해 `editingSaleHistory=true` 상태로 상세 모달을 연다.
- `상세`는 기존 `openSaleDetailModal(sale)`을 그대로 호출한다.
