## 미검증 항목

- **런타임 실동작 미검증**: 원격 세션에 DB·DART/KIS 키·인증 환경이 없어 `bootRun` 기반 preview/상세 실호출 검증은 수행하지 못함. 정적 검증(컴파일·문법·경계 시나리오 추적)으로 대체.
- 실데이터 화면 확인(제안 배지 표시·[적용] 동작·상세 뷰 참고 표시)은 태형님 로컬 기동 후 확인 필요:
  1. 리포트 작성 위저드 7단계 진입 → 정량 5항목 아래 "제안 [등급] [적용] 근거" 라인 표시 확인
  2. [제안 모두 적용] 클릭 → 정량 5항목 select만 채워지고 정성 2항목 불변 확인
  3. 기존 리포트 상세 → 등급 카드 하단 "제안 X" 표시 확인 (스냅샷 없는 리포트는 미표시)

## 판단

정적 검증은 전부 통과. 런타임 미검증 리스크는 additive 응답 필드 + 프론트 null-가드(제안 없으면 UI 숨김) 구조라 기존 화면 회귀 가능성 낮음. 실동작 확인은 push 후 태형님 로컬에서 진행하는 것으로 하고 커밋을 진행한다.
