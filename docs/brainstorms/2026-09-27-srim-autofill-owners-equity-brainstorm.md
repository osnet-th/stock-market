## 이슈 상세 기반 이해
Issue #122로 구현된 S-RIM은 공통 입력(지배주주지분·총 주식수·요구수익률)과 연도별 ROE를 전부 수동 입력받는다. 당시 자동 입력은 "지배주주지분과 정확한 주식수 출처를 확인한 경우만 사용"으로 유보했고, 종목 평가 별도 계산기는 범위에서 제외했다. 이번 작업은 두 유보 항목을 실측으로 해소한다. 계산식·시나리오는 #122 확정본을 그대로 따른다.

## 문제 정의
1. **S-RIM 입력이 전부 수동이다.** 지배주주지분·전기말 지분·총 주식수·기준일을 매번 DART에서 옮겨 적어야 한다.
2. **재무제표 요약에 지배주주지분이 없다.** 요약 표는 DART 주요계정을 미러링하는데 그 API에 해당 계정이 없다. 재무지표 ROE도 분모가 자본총계라 S-RIM 기준과 다르다.
3. **종목 평가 화면에서 적정주가를 볼 수 없다.**

## 목표
- 기업 리포트에서 지배주주지분 기준 숫자를 보고, S-RIM 입력을 버튼 한 번으로 채운다.
- 종목 평가 화면에서 저장 없이 S-RIM 적정주가를 계산한다.
- 주식총수 기준을 사업보고서에서 반기까지로 넓혀 데이터를 최대 6개월 최신화한다.

## 범위
- 리포트 스냅샷에 지배주주지분·비지배지분 노출 + 재무제표 요약 표 행 추가
- 재무지표 ROE를 지배주주 기준으로 교체
- S-RIM 입력 자동 채움 버튼 (지배주주지분 / 전기말 지분 / 합계 유통주식수 / 각 기준일)
- 주식수 라벨을 유통주식수로 변경, 자동 채움 값 출처 표시
- 주식총수 조회를 사업·반기 최신 기준으로 전환, 결산기준일 어댑터 유실 복구
- 종목 평가 화면에 저장 없는 S-RIM 계산 섹션

## 현재 코드 확인 완료 지점
### DART 실측 (삼성전자, 2024~2026)
**주식총수 현황 `stockTotqySttus.json`**

| 보고서 | 코드 | 결과 |
|---|---|---|
| 사업보고서 | 11011 | 보통주/우선주/합계 전부 채워짐 |
| 반기보고서 | 11012 | 사업보고서와 동일한 키·품질 |
| 1분기 / 3분기 | 11013 / 11014 | status 정상이나 합계 1행 값이 전부 비어 있음 |

- 유통주식수 = 발행총수 − 자기주식 항등식이 전 행 성립. 발행총수가 아니라 유통주식수를 써야 한다.
- 구분이 보통주 / 우선주 / 합계 / 비고 4행. 2026 반기 기준 보통주 유통 5,764,191,903 vs 합계 유통 6,566,563,106 — 13.9% 차이.
- 결산기준일이 2026-06-30처럼 정확히 온다.

**전체재무제표 `fnlttSinglAcntAll.json`**
- 지배주주지분 `ifrs-full_EquityAttributableToOwnersOfParent` (BS)
- 비지배지분 `ifrs-full_NoncontrollingInterests` (BS)
- 지배주주순이익 `ifrs-full_ProfitLossAttributableToOwnersOfParent` (IS)
- 반기에서도 동일하게 수신, 전기(frmtrm)가 같은 행에 포함 → 전기말 지분 추가 호출 불필요. 반기에는 전전기 없음.
- BS 지배주주지분과 IS 지배주주순이익의 계정명이 동일 → 재무제표 구분 + 계정 ID 조합 매칭 필수.

### 코드 구조
- 요약 = 주요계정(9계정), 세부 = 전체재무제표. 재무상태표 요약 행은 주요계정 9개를 하드코딩 미러링.
- 주요계정 결측을 전체재무제표로 메우는 선례 존재 (매출액·영업이익·당기순이익 보강).
- 결산기준일은 DART DTO에는 있으나 도메인 모델에 없어 어댑터에서 유실.
- 주식총수 사업보고서 하드코딩 2곳 (리포트 스냅샷 조립기, 주가지표 서비스).
- 종목 평가 도메인은 Entity 없는 조회 전용 도메인. S-RIM 계산 미리보기 API는 무상태 계산기.

## 결정 사항 (2026-09-27 확인)
1. 종목 평가 S-RIM은 저장 없는 즉석 계산기.
2. 지배주주지분은 요약 표 행 추가 + S-RIM 자동 채움 + ROE 기준 교체 3가지 모두 적용.
3. 주식총수 반기 전환을 이번 범위에 포함.
4. 자동 채움은 버튼 방식, 수동 입력을 덮어쓰지 않음.
5. 재무지표 ROE는 기존 행을 지배주주 기준으로 교체 (분자 지배주주순이익, 분모 지배주주지분).
6. 기존 저장 리포트는 그대로. 마이그레이션·일괄 재조립·안내 배지 없음. 재무 새로고침 시에만 새 기준 적용.
7. 종목 평가 자동 채움도 버튼 방식.
8. S-RIM 주식수는 합계 유통주식수.
9. 주식수 라벨을 유통주식수로 바꾸고 자동 채움 값 출처를 표시.
10. 리포트 스냅샷 schemaVersion 2 → 3.

## 결정 사항 보완 (2026-09-28 확인)
issue·brainstorm·plan·현재 코드 대조에서 나온 미결 항목을 권장안대로 확정했다.

- **등급 제안 변화는 의도된 변화.** 현재 ROE는 연결 총계 당기순이익 ÷ 자본총계로 분자·분모 모두 비지배 몫을 포함한다. 주주 관점의 수익성 판단에는 지배주주 기준이 맞으므로, 수익성 제안 등급이 경계값(0/5/10/15%) 근처 종목에서 바뀌는 것은 교정으로 본다. 임계값은 유지하고 화면 기준표 문구에 지배주주 기준을 표기한다.
- **ROE 산출 기준을 데이터로 전달.** 스냅샷에 ROE 기준(지배주주/전체)을 싣고, 값이 없는 v2 스냅샷은 전체 기준으로 본다. 근거 산식은 이 값으로 분기한다. 요약 표 손익계산서 구역에 지배주주순이익 행을 추가한다.
- **v2 리포트 편집 시 자동 채움 버튼 비활성** + "재무 새로고침 후 사용 가능" 한 줄 표시.
- **연도 행 채움 규칙:** ROE 계산 모드 행에만 전기말 지분을 채운다. Y년 행 ← Y−1년 말 지배주주지분. 값이 없는 연도는 비움. 행 생성 없음. 예상 지분·예상 순이익은 채우지 않음.
- **지배주주지분 기준 시점:** 최신 정기보고서 컬럼(분기 포함) 우선, 없으면 기준연도 연간 값. 분기 값은 구현 전 실측.
- **출처 표시는 입력 화면에서만**, 저장하지 않음 (S-RIM JSONB 불변). 라벨은 입력 폼과 상세 조회 두 곳 모두 변경.
- **종목 평가 S-RIM에 기준 주가 비교 포함.**
- **미국 리포트 지배주주 ROE와 주가지표 서비스 반기 전환을 이번 범위에 포함한다.** 9/27 범위 최소 결정을 번복했다. 미국 SEC 조회는 이미 지배주주 태그를 우선하므로 기준 표기·혼합 방지만 필요하고, 주가지표 서비스는 호출처 2곳(기업 리포트, 챗봇 컨텍스트) 회귀 확인이 필요하다.
- **단위 테스트를 작성한다.** 시나리오는 대화로 합의 후 plan에 반영한다.

## 리스크
- ROE 기준 교체 + 반기 전환으로 기존 리포트 대비 수치가 달라진다 (삼성전자 자본총계 대비 지배주주지분 차이 2.75%, 유통주식수 차이 1.09%).
- 저장된 스냅샷은 새로고침 전까지 옛 기준을 유지해 기준이 한동안 섞인다.
- 기존 유통주식수 조회(보통주 우선)는 EPS·BPS·시가총액용으로 유지하고 S-RIM용 합계 조회를 별도로 둔다.
