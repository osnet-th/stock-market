## What We're Building

종목별로 **기업분석리포트를 작성(등록)하고 조회**하는 기능. 리포트는 아래 7개 섹션으로 구성된다.

| # | 섹션 | 내용 |
|---|------|------|
| 1 | 회사 개요 | 회사명, 설립일, 연혁, 경영이념, 사업내용, 매입처/판매처 분산 여부 |
| 2 | 실적 추이 | 과거 5~10년 매출/이익 추이 그래프, 경쟁사 사업부문별 비교 메모 |
| 3 | 재무제표 요약 | 재무상태표/손익계산서/현금흐름표 주요 항목 3~5년치 + 급변 항목 원인 메모 |
| 4 | 재무지표 | 건전성(자기자본비율·유동비율·부채비율), 수익성(영업이익률·ROE·ROA), 성장성(매출·영업이익 성장률) — 기준치 대비 판정 |
| 5 | 주가지표 | PER, PBR, PSR, PCFR, PER×PBR, EV/EBITDA, ROIC, 발생액/총자산, 시가총액, 예상 수익률 |
| 6 | 기업가치 | 청산가치(조정자산 − 총부채) vs 시가총액, DCF 보수/낙관 시나리오 |
| 7 | 투자판단 | 7항목(자산 저평가, 수익 저평가, 재무건전성, 수익성, 성장성, 사업역량, 주주중시) A~E 등급 + 종합 코멘트. 한 항목이라도 A면 매수재료 하이라이트 |

부가: 위험 기업 시그널 체크(유동부채>유동자산, 자기자본비율 20% 이하, 순자산 마이너스, 재고/매출채권 과다, 증자 이력), 주주 동향(대주주, 배당성향, 자사주).

## 신규 개발 필요

1. **회사 개요 자동 채움**: DART 기업개황 API(`company.json` — 대표자, 설립일, 업종 등) 어댑터 추가. 연혁/경영이념/사업내용은 자동화 불가 → 수동 입력.
2. **타임라인 10년 확장**: DART 재무 API는 2015 사업연도부터 제공 → 현재 최대 약 11개년. 연 단위 호출이 늘어나므로(연도당 1회 이상) 캐시/스냅샷 전략 필요.
3. **재무지표 판정**: 기준치(자기자본비율 40%/20%, 유동비율 100%, 부채비율 200%/300%, 영업이익률 5%/10%, ROE 10%/5%, ROA 5%, 성장률 10%)로 양호/주의/위험 신호등 표시.
4. **주가지표 확장**: PSR(시총/매출), PCFR(시총/영업CF), PER×PBR, 발생액/총자산((순이익−영업CF)/총자산) — 기존 데이터로 계산 가능. ROIC는 세후영업이익/투하자본으로 근사.
5. **청산가치 계산기**: 조정자산 비율표(현금·유가증권 100%, 매출채권 85%, 재고·투자·유형자산 50%, 무형·기타유동 0%)를 BS 계정 트리에 적용 → 조정자산 − 총부채 = 청산가치, 시가총액과 비교.
6. **DCF 계산기**: 보수(순현금 + FCF/R, R=10%, 성장 0%) / 낙관(5년간 연 20% 성장 후 성장 0%). FCF = 영업CF − CapEx(기존 정의 재사용). 순현금 = 현금성자산 − 총차입금.
7. **투자판단 7항목 A~E**: 등급 저장 + 코멘트. 정량 5항목은 자동 제안 가능(아래 Open Question).
8. **리포트 Entity + CRUD API + 화면**: 신규 도메인 패키지, 리포트 목록/작성/조회/수정 화면.

## 핵심 설계 제안

### 1. 하이브리드 구조: 자동 산출 + 수동 입력

- **자동 산출(시스템)**: 실적 추이, 재무제표 요약 수치, 재무지표, 주가지표, 청산가치, DCF 기본 시나리오, 회사 기본정보(DART 기업개황).
- **수동 입력(태형님)**: 연혁·경영이념·사업내용, 매입처/판매처 분산 평가, 급변 항목 원인 메모, 경쟁사 비교 메모, 투자판단 등급·코멘트.
- 책의 방법론(리포트에 "옮겨 씀") 자체가 시점 기록이므로 **저장 시점 스냅샷** 방식이 자연스러움.

### 2. 스냅샷 저장 (권장) vs 조회 시 재계산

- **권장: 저장 시 자동 산출값을 JSON 스냅샷으로 리포트에 저장 + "데이터 새로고침" 버튼.**
  - 장점: 조회 즉시 렌더(외부 API 무호출), DART/KIS 호출량 절약, "그때 그렇게 판단한 근거" 보존.
  - 단점: 최신성은 새로고침에 의존 → 리포트에 기준일 표시로 보완.
- 대안(조회 시 재계산): 항상 최신이지만 조회마다 DART 10개년 + KIS 호출 발생, 과거 판단 근거 유실.

### 3. 투자판단 자동 제안 + 수동 오버라이드 (권장)

- 정량 5항목 자동 제안: 자산 저평가(청산가치/시총, PBR), 수익 저평가(PER, DCF/시총), 재무건전성(자기자본비율·부채비율·유동비율), 수익성(영업이익률·ROE·ROA), 성장성(매출·이익 성장률).
- 정성 2항목(사업역량, 주주중시)은 수동 기본. 주주중시는 배당성향·자사주 데이터를 참고자료로 노출.
- 7항목 모두 최종 등급은 태형님이 확정(오버라이드 가능), 자동 제안값과 확정값을 함께 저장.

### 4. 아키텍처 (plan에서 확정, Entity는 Approval Gate 대상)

- 신규 도메인 패키지 `companyreport/` (domain/application/infrastructure/presentation, 기존 레이어 규칙 준수).
- Entity(안): `CompanyAnalysisReport` — 종목코드/기준일/수동 입력 필드/투자판단 등급/스냅샷 JSON. 도메인 간 참조는 stockCode만 사용(ID 기반 참조 원칙).
- 자동 산출은 application 계층에서 기존 `stock`/`stockevaluation` 서비스 조합(직접 외부 API 호출 없음).
- 프론트: 신규 파티션 + Alpine 컴포넌트, 차트는 `financial.js` ctx bag 패턴 재사용(canvas ID 접두어 `report-`).

## Edge Cases

- **DART 데이터 없음/부족**: 신규 상장(10년 미만), 우선주, 비상장 → 가용 연도만으로 작성, 빈 섹션 허용.
- **청산가치 계정 매핑 실패**: 계정 트리 앵커에 안 걸리는 항목 → "기타" 0% 보수 처리 + 미분류 목록 표시.
- **DCF 음수 FCF**: 시나리오 계산 불가 표시(에러 아님).
- **분기 최신치 혼합**: 실적 추이는 연간 기준, 올해는 최신 분기 병기(기존 타임라인 규칙 재사용).
- **동일 종목 리포트 중복**: 종목당 여러 버전 허용(작성일 구분) — 시점별 판단 기록이 목적.
- **10년 호출량**: 새로고침 시에만 발생, 기존 DART 캐시 활용. 스냅샷 방식이면 평시 부담 없음.

| `elestock` 임원·주요주주 소유보고 | 임원/주요주주별 소유수, 증감 | 보고접수일 제공 (매매시기 근사) | **최근 약 2년치만 반환** |

결론: **명단+지분율의 과거 10년 이력은 자동화 가능**(hyslrSttus 연도별). **매매 시기는 최근 2년은 보고일 단위로 근사 가능**(majorstock/elestock), 정확한 체결일·그 이전 이력은 공시 원문 열람 필요(리포트에서는 DART 뷰어 링크로 대체).
