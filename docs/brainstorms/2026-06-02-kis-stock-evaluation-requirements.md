# KIS 국내주식 종목정보 기반 종목 평가 기능

## Problem Frame

매수 전에 종목을 판단할 수 있는 독립적인 리서치 화면이 없다. 현재 종목 검색은 포트폴리오 추가 폼의 한 단계(`searchStock` → `selectStock` → addForm)일 뿐이고, 재무상세(DART) 탭은 이미 보유한 종목에만 노출된다. 따라서 "이 종목을 살지 말지" 판단하는 평가 도구가 들어갈 자리가 없다.

한국투자증권 국내주식[종목정보] API군(재무제표·비율, 종목추정실적, 신용가능종목, 예탁원 일정)을 활용하여, 보유 여부와 무관하게 종목을 평가할 수 있는 **독립 "종목 평가" 화면**을 신설한다.

## User Flow

```
[종목 평가] 메뉴 (신규)
  └─ 종목 검색 (KRX, 기존 searchStocks 재사용)
       └─ 종목 선택 → 평가 상세 화면
            ├─ 상단: 종목 기본정보 (상품기본조회 search-info)
            ├─ [재무] 탭 ── 대차대조표 / 손익계산서 / 재무·수익성·기타·안정성·성장성 비율
            ├─ [추정·신용] 탭 ── 종목추정실적 / 당사 신용가능종목 여부
            └─ [일정] 탭 ── 예탁원정보 12종 일정 (배당/증자/합병 등)
```

- 보유 여부와 무관 (포트폴리오에 없는 종목도 평가 가능)
- 모든 데이터는 종목 선택/탭 진입 시 KIS API 온디맨드 호출
- 국내(KRX) 종목 한정

## Requirements

**화면 / 네비게이션**

- R1. 좌측 메뉴(또는 상단 네비)에 독립 "종목 평가" 진입점을 추가한다.
- R2. 평가 화면 상단에 KRX 종목 검색창을 두고, 기존 `GET /api/stocks/search`(searchStocks)를 재사용한다.
- R3. 종목 선택 시 평가 상세 영역이 렌더링되며, 상단에 종목 기본정보(상품기본조회 `search-info`)를 표시한다.
- R4. 평가 상세는 [재무] / [추정·신용] / [일정] 탭으로 구성한다.

**재무 그룹 (Phase 1)**

- R5. [재무] 탭에서 다음 7종 KIS API 값을 표시한다.
  - 대차대조표, 손익계산서, 재무비율, 수익성비율, 기타주요비율, 안정성비율, 성장성비율
- R6. 연도/분기 등 KIS API가 요구하는 조회 파라미터를 사용자가 선택할 수 있어야 한다 (분류 코드 형태는 Planning에서 확정).

**추정·신용 그룹 (Phase 2)**

- R7. [추정·신용] 탭에서 종목추정실적을 표시한다.
- R8. 당사 신용가능종목 조회 결과로 해당 종목의 신용거래 가능 여부를 표시한다.

**예탁원 일정 그룹 (Phase 3)**

- R9. [일정] 탭에서 예탁원정보 12종 일정을 표시한다.
  - 배당일정, 주식매수청구일정, 합병/분할일정, 액면교체일정, 자본감소일정, 상장정보일정, 공모주청약일정, 실권주일정, 의무예치일정, 유상증자일정, 무상증자일정, 주주총회일정
- R10. 예탁원 일정 API는 종목 단위가 아닌 기간(날짜 범위) 단위 조회일 수 있으므로, 조회 방식은 Planning에서 API별로 확정한다.

**데이터 조회 방식**

- R11. DB 저장 없이 온디맨드 KIS 호출 (탭/하위 항목 진입 시 호출). 자동 폴링·스케줄러 없음.
- R12. 기존 `KisApiClient` / `KisTokenManager` 인증·호출 인프라를 재사용한다.

**기존 기능 비침범**

- R13. 기존 DART 기반 재무상세(`StockFinancialController`, financial.js)는 변경하지 않는다.
- R14. 포트폴리오 추가 폼의 종목 검색 흐름(`searchStock`/`selectStock`)을 변경하지 않는다.

## Success Criteria

- "종목 평가" 메뉴에서 KRX 종목을 검색·선택하면 재무/추정·신용/일정 탭으로 KIS 데이터를 조회할 수 있다.
- 보유하지 않은 종목도 평가할 수 있다.
- 기존 DART 재무상세·포트폴리오 검색 흐름에 영향이 없다.

## Scope Boundaries

- 해외주식은 범위 외 (국내 KRX 한정).
- 평가 데이터를 포트폴리오 보유 종목 화면에 연동하지 않음 (별도 화면).
- KIS 데이터 DB 저장·캐싱 스케줄러 없음 (온디맨드만; 토큰 캐시는 기존 것 재사용).
- 종목 추천·자동 점수화 등 가공 로직은 범위 외 (원천 API 값 표시 중심).

## Key Decisions

- **독립 "종목 평가" 메뉴 신설 (A안)**: 평가는 매수 전 리서치 도구이므로, 보유 맥락(포트폴리오)·보유 종목 전용 재무상세와 분리. 보유 여부 무관한 검색→평가 흐름이 개념에 부합.
- **DART 재무상세와 별도 도메인**: 데이터 출처(KIS vs DART)와 목적(평가 vs 보유 상세)이 다르므로, 해외뉴스(`overseasnews`) 구현 패턴처럼 독립 도메인으로 구현.
- **단계별 단일 plan**: 22종 API를 한 plan에 Phase 0~3 체크리스트로 관리. Phase 0에서 셸(메뉴·검색·평가 화면·기본정보)을 먼저 세우고 이후 그룹별로 채운다.
- **온디맨드 호출**: 평가용 조회성 데이터이므로 DB 저장 대신 실시간 호출 (해외뉴스와 동일 원칙).

## API Inventory & Phasing

> 정확한 경로/tr_id/파라미터/응답 필드는 Planning에서 KIS 포털(시작점: `/uapi/domestic-stock/v1/quotations/search-info`)로 확정. 본 문서는 추측 스펙을 확정값으로 기재하지 않는다.

**Phase 0 — 셸 (1종 + 화면)**
- 상품기본조회 (`search-info`) — 종목 기본정보 헤더
- 신규 메뉴/라우트, KRX 검색 재사용, 평가 상세 탭 골격, 신규 도메인 패키지

**Phase 1 — 재무제표·비율 (7종)**
- 대차대조표 / 손익계산서 / 재무비율 / 수익성비율 / 기타주요비율 / 안정성비율 / 성장성비율

**Phase 2 — 추정·신용 (2종)**
- 종목추정실적 / 당사 신용가능종목

**Phase 3 — 예탁원정보 일정 (12종)**
- 배당 / 주식매수청구 / 합병·분할 / 액면교체 / 자본감소 / 상장정보 / 공모주청약 / 실권주 / 의무예치 / 유상증자 / 무상증자 / 주주총회 일정

합계: 22종.
