# 포트폴리오 배당 집계 KSD 실지급일 기준 전환 단위 테스트 계획

- 승인: 2026-10-03 태형님 승인 (plan 승인 요청과 함께 제시한 A1~A6, S1~S11)

## 테스트 대상
- 대상 클래스/메서드
  - `KisDividendScheduleAdapter.findCashDividends(stockCode, from, to)`
  - `PortfolioIncomeService.summarize(items, evaluation)`
- 대상 유스케이스
  - KIS 배당일정 응답을 배당 일정 모델로 바꾸고 종목·기간 단위로 캐시한다.
  - 국내 주식 배당을 지급일 기준으로, 해외 주식·빈 ETF·이자는 월 평균으로 집계한다. 조회 실패 시 폴백한다.

## 테스트 범위
- 포함: 응답 변환 규칙, 캐시와 실패 미캐시, 이달·연 예상 기간 필터, 입력 배당률 방식, 폴백, 시가배당률 분모, KST 월 경계, 수량·시장 값 예외
- 제외: 컨트롤러, 스프링 컨텍스트, 실제 KIS 호출, `PortfolioSummaryService` 연결, 화면 캡션(CP3 브라우저 하네스로 확인)

## Mock 대상
- 외부 API: `KisKsdScheduleClient` (어댑터 테스트)
- 기타 외부 의존성: `DividendSchedulePort` (집계 테스트)
- 시계: 고정 `Clock` — 기본 2026-10-15 10:00 KST(`2026-10-15T01:00:00Z`, `Asia/Seoul`)
  - 조회 기간 2025-05-01 ~ 2026-10-31, 연 예상 기간 2025-11-01 ~ 2026-10-31, 이달 2026-10-01 ~ 2026-10-31
- 검증은 반환값 상태로만 한다. 호출 여부·횟수는 검증하지 않는다.
