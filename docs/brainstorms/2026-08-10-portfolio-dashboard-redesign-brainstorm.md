## 현재 화면 대비 v3 진단

### v3에서 이미 해소된 것

| 영역 | 반영 내용 |
|------|-----------|
| 화면 구조 | 보유 자산 / 매도 이력 / 목표 배분 / 분석 4탭 + 배지 카운트 |
| 자산 추가 | 11개 자산군, 종목 검색, 거래소→통화/국가/환율 자동, 연결 현금계좌 |
| 행 액션 | 추가매수·납입(자산군 자동 분기), 매도, 이력, 삭제 + 매도이력 삭제 차단 모달 |
| 매도 | 환율·차감액·입금계좌·사유·메모·미입금 + 실입금/실현손익 프리뷰 |
| 납입 | 납입 모달 + 이력 + 리마인더(스누즈) |
| 매도 이력 | KPI 4종, 월별 그룹 소계, 미입금 집계, 기여율, 상세 모달 |
| 목표 배분 | 서버 저장 표기, 밴드 ±%p 조절, 목표 설정 모달(상위 버킷 + 자산군별 + 암호화폐 제외 토글), 0기준 편차 막대, 리밸런싱 제안 |
| 분석 | 종목 선택 → 재무상세, DART/SEC 분기, 패널 폭 리사이즈 + localStorage 저장 |
| 헤더 | 시세 캐시 나이·TTL, 시세 새로고침, 마감 알림 토글 |
| 목록 | 도넛+범례, 현금성 서브그룹(예금/적금/CMA), 계좌 연결/미연결 + 미연결 건수, 그룹 소계, 빈 자산군 안내 |

### v3에 아직 없는 것 (현재 화면 대비 기능 손실)

1. **자산 수정(Edit) 버튼 없음** — 행 액션 7개(키워드·재무상세·AI분석·추가매수/납입·매도·이력·삭제)에 `수정`이 빠짐. 현재 `openEditModal`/`submitEditItem`은 자산명·수량·평단·종목 재검색·연결 현금계좌 변경을 지원. v3에선 항목 자체를 고칠 수단이 없음.
2. **뉴스 dead branch** — 스크립트에 `isNews`, `newsTabs`(종목 뉴스/해외주식 속보/해외뉴스 종합), `articles`, `pages`, `fetchNews`, 키워드 add/remove 핸들러가 모두 정의돼 있으나 템플릿에 해당 섹션이 없고 `tabs` 배열에도 news가 없어 도달 불가. 키워드 모달 문구("키워드 메뉴에서 확인합니다")로 보아 포트폴리오 밖으로 이관 의도로 추정.
3. **매도 이력 수정 폼 없음** — 상세 모달에 `수정` 버튼만 있고 편집 폼 부재. 현재는 수량·단가·차감액·실입금·사유·메모 인라인 수정(`submitSaleEdit`) 지원.
4. **재무상세 깊이 축소** — 연도별 추세의 재무제표(IS/BS/CF)·지표클래스 확장, CFS/OFS 구분, 연도·보고서코드(사업/반기/분기) 선택, 계정 필터 없음. 공시는 유형 다중 필터·기간(1/3/6/12개월)·원문 링크 없이 3건 고정. SEC는 분기/연간 전환·EDGAR 링크 없음.
5. **AI분석 미연동** — `onAi`/`runAi`가 화면 전환·`forceUpdate`뿐. 현재는 챗 패널로 분석 프롬프트 전달(`openChatForPortfolioStockAnalysis`).
6. **자산군별 액션 노출 규칙 소실** — 모든 행에 키워드·재무상세·AI분석 3버튼 노출. 현재는 ETF·현금엔 키워드 숨김, ETF 및 KR/US 외 종목엔 재무상세·AI분석 숨김, 주식만 매도, 현금성·펀드만 납입.
7. **목표 합계 100% 검증 없음** — `targetSum` 표시만. 현재는 합계 100 미달/초과 시 경고 색상 + 저장 차단, 안전자산 입력 시 투자자산 자동 계산.
8. **로딩/에러/재시도 상태 없음** — 스피너, 실패 안내, 재시도 버튼 부재.

- 포트폴리오에서 제거: 종목 카드 인라인 뉴스 목록·페이징, 종목별 `뉴스 수집` 버튼, 해외속보/해외뉴스종합 패널, 카드 클릭 시 뉴스 펼침 동작

- 제거 대상 상태·핸들러: `portfolio.news`, `portfolio.overseasNews`, `selectedNewsItemId`, `collectingItemId`, `selectPortfolioNewsItem`, `loadPortfolioNews`, `collectPortfolioNews`, `toggleOverseasNews`, `switchOverseasNewsTab`, `loadOverseasNews`, `loadMoreOverseasNews`

## 신규 백엔드 4종 (이번 범위 포함 — 태형님 결정)

| 기능 | 필요한 작업 |
|------|-------------|
| 자산 추이 스냅샷 + `스냅샷 저장` | 신규 테이블(사용자·일자·총평가액·총투자원금), 저장/조회 API, 최근 12개월 조회. 현행 `SaleSnapshot`은 매도 시점 기록 전용이라 재사용 불가 |
| 이달 배당·이자 / 연 예상 / 시가배당률 | 주식 배당은 `stockevaluation`(KSD 일정) 데이터를 포트폴리오 보유 수량과 결합, 예적금·채권 이자는 금리·만기 기반 산출. 집계 서비스 신설 |
| CAGR · 보유일수 | 최초 매수일(`StockPurchaseHistory.purchasedAt` 최소값) 기준 산출. 자산군 혼재 시 전체 포트폴리오 단위로 계산 |
| 환차손익 | **`StockPurchaseHistoryEntity`에 매수 시점 환율 컬럼이 없음** → 컬럼 추가 + 마이그레이션 필요. 기존 데이터는 환율 미상이므로 미산출 처리 |

## 구현 방향 (초안)

- **프론트엔드**: `partials/portfolio.html` 전면 재구성(4탭) + 모달 partials 정리, `js/components/portfolio.js` 상태·헬퍼 재배치, 뉴스 관련 상태·핸들러 제거.
- `portfolio.activeTab`을 현행 items/sales 2값 → holdings/sales/targets/analysis 4값으로 확장.
- 재무상세는 현행 패널 로직(`financial.js` 연동·폭 저장·필터 일체)을 그대로 재사용하고 분석 탭으로 이동 배치.
- **백엔드**: `AssetType.PENSION` 추가, 스냅샷 도메인 신설, 배당·이자 집계 서비스 신설, 매수 이력 환율 컬럼 추가, CAGR 산출 로직 추가. 마이그레이션은 `db/migration`에 추가.
- 기존 API 재사용: `/api/portfolio/**`, `/api/portfolio/allocation/status`, 재무·공시 API.
- 범위가 커서 plan 단계에서 **프론트 재구성 / 자산군 추가 / 신규 집계 API**를 단계로 쪼개 체크리스트를 구성한다.

## 검토한 대안 (채택 안 함)

- **행 액션을 `⋯` 케밥 메뉴로 접기** — 관리 열 폭은 줄지만 재무상세·AI분석 접근에 클릭이 1단계 늘어남. 자산군별 노출 규칙만으로 폭 문제가 해소되므로 불필요.
- **v3를 그대로 전면 교체** — 자산 수정·뉴스·매도 수정·재무 필터가 사라져 기능 후퇴. 누락분 보강 후 교체로 결론.
- **상단 요약만 리디자인하고 하단 목록은 현행 유지**(v1 검토 시 권고안) — v3에서 목록까지 테이블로 정리되면서 실효성 낮아짐.

## Edge Cases

- 자산군에 항목이 0건일 때 — v3의 "부동산·암호화폐·기타 미등록" 안내 + 첫 자산 추가 CTA 유지.
- 매도 이력이 있는 항목 삭제 — 차단 모달 + 매도 이력 탭 이동 동선 유지(현행 `hasSaleHistories` 가드).
- 목표 미설정 사용자 — 목표 배분 탭 진입 시 안내 문구 분기.
- 암호화폐 배분 제외 토글 OFF일 때 — 편차·리밸런싱 계산에 포함되도록 기준 총액 전환.
- 시세 조회 실패·캐시 만료 — 헤더 TTL 표기와 재시도 경로 필요.
- 해외 항목의 평단환율 부재(기존 데이터) — 환차손익 미산출 처리.
- 스냅샷이 0건·1건일 때 — 자산 추이 차트는 안내 문구로 대체, 같은 날 중복 저장은 덮어쓰기.
- 배당 데이터가 없는 종목(ETF·해외 일부) — 이달 배당·이자 집계에서 제외하고 집계 기준을 표기.
- 최초 매수일이 없는 항목(수기 등록 자산) — CAGR 산출에서 제외.
- 연금 자산군 신설 전 등록된 IRP·연금저축 항목(현재 `FUND`/`OTHER`로 등록됐을 가능성) — 자동 이관하지 않고 사용자가 수정으로 변경.
- 매도 이력 전체 기간 조회 — 건수가 많을 때 월별 그룹 렌더 부하 확인 필요.

## 범위 밖 (하지 않음)

- 증권사 주문 연동 / 자동 리밸런싱 실행 (목업에도 "금액 제안까지만" 명시)
- CSV 내보내기
- 포트폴리오 내 뉴스 기사 열람 (키워드 메뉴로 이관)
- 대시보드 화면·키워드 메뉴 자체의 재설계 (이관에 필요한 최소 연동만)
- 차트 라이브러리 교체
- 기존 데이터의 연금 자산군 자동 마이그레이션
