- 시드 데이터로 자산 유형 9종 전체를 등록해 포트폴리오 화면을 확인하자 표시 문제가 드러남.
- 태형님 피드백 (2026-08-02): "값 표시 그래프가 조금 깨져있고 그래프로 확인하는 값이 너무 번잡해" + 목표 자산 배분 카드 캡처와 함께 "이 부분도 솔직히 파악이 힘들어"
- 대상 파일: `partials/portfolio.html`(도넛·자산 비중·목표 배분 카드), `js/components/portfolio.js`(Chart.js 도넛 설정·배분 렌더 헬퍼)

## 문제 진단 (localhost:8080 실측)

### 1. 도넛 중앙 텍스트가 링과 겹침 (깨짐)

- Chart.js 범례가 캔버스 내부 하단(`legend.position: 'bottom'`)에 그려지는데, 자산 유형 9종이면 범례가 4줄로 늘어남.
- 280px 캔버스에서 차트 영역 높이가 158px로 축소 → 도넛 구멍 지름 약 103px.
- 중앙 오버레이는 `portfolio.html:63`의 고정 보정(`bottom: 48px`, 범례 1~2줄 가정)이라 실제 원 중심보다 37px 아래에 위치.
- 금액 텍스트 폭 114px > 구멍 103px → "총 평가 60,174,940원"이 링 위에 겹침.
- 자산 유형이 2~3종일 때는 드러나지 않던 문제.

### 2. 자산 비중 미니 막대의 소수% 뭉개짐 (깨짐)

- `portfolio.html:77` 막대가 높이 20px(`h-5`) + `rounded-full`.
- 원자재 2% → 폭 6px, 펀드 3% → 9px: 알약 반경(10px)보다 좁아 짜부러진 타원/점으로 렌더링.

### 3. 목표 자산 배분 카드 해석 부담 (번잡)

- 막대는 "현재 비율"만 채우고 목표는 설명 없는 검은 세로선(호버해야 "목표 비율" 표시).
- 색이 방향 정보를 담지 않음: 밴드 초과면 부족·초과 모두 빨강(주식 -21.7%p와 부동산 +25.0%p가 같은 색), 안전자산은 996만원 부족인데 초록.
- 편차 "−9,963,711원 (−17.4%p)"가 손실처럼 읽힘 — 실제 의미는 "996만원 부족".
- 버킷당 수치 6개(현재%·목표%·배지·편차원·편차%p·현재원/목표원) — 같은 사실의 3중 표기.
- 상위 버킷은 전체 대비 %, 하위는 "투자자산 총액 대비" %라 기준이 달라 직접 비교 불가.
- 자산유형별 비중이 도넛 범례·자산 비중 카드·투자자산 내부 비율 세 곳에 중복.

## What We're Building

1. **도넛 정리**: 캔버스 내장 범례 제거(`legend.display: false`) — 우측 "자산 비중" 카드가 이미 범례 역할. 중앙 텍스트를 원 중심에 정확히 배치(고정 오프셋 제거).
2. **미니 막대 수정**: `rounded-full` → 작은 radius로 변경해 소수% 뭉개짐 해소.
3. **목표 자산 배분 카드 재설계 (편차 중심)**:
   - 0 기준 다이버징 편차 막대 — 왼쪽 부족 / 오른쪽 초과, 허용밴드(±밴드%p)는 중앙 음영으로 표시.
   - 색 = 행동 방향: 초과=빨강(줄이기), 부족=파랑(채우기), 밴드 내=회색(조용히).
   - 편차 라벨을 행동 언어로: "996만원 부족 / 751만원 많음", 금액은 만원 단위 축약.
   - 카드 상단에 리밸런싱 요약 1줄: "투자자산에서 안전자산으로 약 996만원 이동 시 목표 도달".
   - 현재/목표 %는 보조 열로 유지, 풀자리수 원 단위 병기(현재원/목표원 캡션)는 제거.
   - 범례(색 의미·밴드 음영 안내)와 "배분 제외: 암호화폐 N건" 문구 유지.

## 확정된 결정 (태형님, 2026-08-02)

| 항목 | 결정 |
|------|------|
| 개선 범위 | 깨짐 2건 수정 + 목표 배분 카드 편차 중심 재설계 (목업 방향 승인) |
| 도넛 범례 | 제거 — 우측 자산 비중 카드가 범례 대체 |
| 편차 막대 | 0 기준 다이버징, 색=행동 방향(초과 빨강/부족 파랑/밴드 내 회색) |
| 금액 표기 | 만원 단위 축약 + 행동 언어("부족/많음") |
| 리밸런싱 요약 | 카드 상단 1줄 표시 (표시만, 실행 기능 없음) |

## 구현 방향

- **프론트엔드 전용** — 서버 API·Entity·비즈니스 로직 변경 없음. `/api/portfolio/allocation/status` 응답(현재·목표·편차·밴드초과)을 그대로 사용.
- `partials/portfolio.html`: 도넛 오버레이·자산 비중 막대·목표 배분 카드 마크업 수정.
- `js/components/portfolio.js`: Chart.js legend 옵션 제거, 다이버징 막대 스타일 헬퍼·만원 축약 포맷·리밸런싱 요약 문구 생성 추가.
- 편차 막대 스케일: 최대 |편차%p|에 맞춰 동적 산정(최소 밴드×2 이상 확보) — 소수 편차도 식별 가능하게.

## 검토한 대안 (채택 안 함)

- **도넛 범례를 캔버스 밖 HTML로 이동** — 우측 카드와 정보 중복이 그대로 남음. 제거가 답.
- **중앙 텍스트를 Chart.js 플러그인으로 캔버스에 직접 그리기** — 범례 제거 후에는 CSS 오버레이 중앙 정렬로 충분. 플러그인 추가는 과함.
- **현재/목표 이중 막대(불릿 차트 유지 + 색 정리)** — 편차(행동 필요량)가 여전히 암산 대상. 편차 중심 다이버징으로 대체.
- **목표 배분 카드 접기/펼치기** — 재설계로 밀도가 충분히 내려가 접기 불필요. 후속 검토 여지만 남김.

## Edge Cases

- 자산 유형이 1~2종뿐일 때 — 범례 제거 후에도 우측 카드로 확인 가능, 도넛 정상.
- 목표 미설정 자산군(targetRatio null) — 편차 계산 불가 → 현재 % 표시 + "목표 미설정" 라벨 유지.
- 편차 0(예: 금 +0.0%p) — "목표 일치"로 표시, 막대 없음.
- 밴드 값 사용자 변경 시 음영 폭 동적 반영.
- 리밸런싱 요약은 상위 버킷 편차 기준(안전 부족=투자→안전 이동), 밴드 내면 "목표 범위 안"으로 표시.
- 총 평가액 0·목표 미설정 사용자 — 기존 안내 문구 분기 유지.

## 범위 밖 (하지 않음)

- 대시보드 포트폴리오 카드 변경

- 자동 리밸런싱 실행 기능
- 보유 자산 목록(하단 아코디언) 영역 변경
