# #138 [enhancement] 적금 자동납입 처리 방식 선택(알림 확인 / 자동 반영)

- url: https://github.com/osnet-th/stock-market/issues/138
- state: OPEN
- saved: 2026-10-06 10:05

## 본문

## 작업 내용
- 현금성 자산(예금·적금·CMA)의 자동납입 설정에 처리 방식 선택 추가: 알림 받고 직접 납입(현행) / 납입일에 자동 납입
- 자동 납입 항목은 납입일 00:10(KST)에 월 납입액을 납입 이력(메모 "자동 납입")에 기록하고 원금에 더함
- 알림 방식의 [납입]은 월 납입액과 오늘 날짜를 미리 채운 납입 창을 엶
- 보유 자산 설명 줄에 "자동 납입" 표시

## 완료 조건
- 자동납입을 설정할 때 처리 방식을 고를 수 있고, 기존 항목과 새 항목의 기본값은 알림 확인이다
- 자동 납입 항목은 납입일에 한 번만 기록된다. 이번 달 기록이 이미 있거나 시작일 전·만기일 이후면 건너뛴다
- 자동 기록이 빠진 달은 기존 당일·미납 알림이 그대로 뜬다
- 알림 확인 항목은 지금과 같이 동작한다

## 배경
- #99는 "완전 자동 기록 대신 알림 + 사용자 확인"을 전제로 한다. 이 이슈는 그 전제를 항목마다 고르게 바꾼다.

## 범위 밖
- 메일 알림·알림 설정(#99), 은행 계좌·자동이체 연동, 만기 지난 항목의 알림 판정 변경, 놓친 달 소급 기록, 펀드·연금 자동 납입
