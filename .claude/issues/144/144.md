## 본문

## 작업 내용
- 앱 안에 MCP 서버(Streamable HTTP)를 두고, Claude(claude.ai 웹·데스크톱·모바일 커스텀 커넥터)와 Claude Code에서 연결할 수 있게 한다
- 조회 도구 10개를 제공한다
  - 기업 리포트 요약, 내 리포트 목록·상세
  - S-RIM 적정주가 계산(종목코드만으로 계산, 요구수익률·ROE 가정은 선택), 채권 기준수익률
  - 보유 종목, 포트폴리오 요약(예상 배당·이자 포함), 종목 배당 일정
  - 경제지표, 뉴스 검색
- 연결 인증은 OAuth로 한다. 연결할 때 앱 로그인(카카오)으로 본인을 확인하고, 본인 데이터만 조회한다

## 완료 조건
- claude.ai에 커스텀 커넥터로 추가하고 카카오 로그인으로 연결하면 도구 10개를 쓸 수 있다
- Claude Code에 HTTP MCP 서버로 추가해도 같은 도구를 쓸 수 있다
- 도구 응답에 기준연도·보고서 종류·기준일·단위가 들어 있다
- 다른 사용자의 리포트·포트폴리오는 조회되지 않는다
- 인증 없이 MCP 엔드포인트를 호출하면 거절된다(dev 포함)
- 기존 화면 로그인과 API 동작은 바뀌지 않는다

## 배경
- 기업 리포트·S-RIM·포트폴리오 정보가 화면에만 있어 여러 종목 비교나 조건을 바꾼 재계산을 하려면 화면을 여러 번 오가야 한다
- Claude에서 앱 데이터를 불러와 종목 분석, 종목 비교, 리포트 작성 보조, 포트폴리오 점검, 경제지표·뉴스와 함께 해석하는 데 쓰려 한다

## 범위 밖
- 쓰기 도구(리포트 생성·수정·메모 저장, 포트폴리오 변경)
- 기존 Gemini 챗봇 변경, 기존 화면용 로그인 방식 변경
- 해외 종목 S-RIM 자동 계산
