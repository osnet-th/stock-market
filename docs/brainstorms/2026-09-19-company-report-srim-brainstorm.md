# 기업 리포트 S-RIM 적정주가

gate: docs/gates/2026-09-19-company-report-srim-gates.md

## 확정 요구사항
- 기업 리포트 작성·수정·조회에 S-RIM 섹션을 추가한다. 종목 평가·포트폴리오 연결은 제외한다.
- 공통 입력은 지배주주지분, 총 주식수, 사용자 직접 입력 요구수익률이다. 금액·주식수 기준일을 보존한다.
- 연도 추가와 연도별 ROE 직접 입력 또는 근거값 계산을 지원한다. 컨센서스 API를 전제하지 않는다.
- ROE 계산 입력: 전기말 지배주주지분, 당기말 예상 지배주주지분, 당기 예상 지배주주순이익.
- 예상 ROE = 예상 지배주주순이익 / ((전기말 지배주주지분 + 당기말 예상 지배주주지분) / 2). 표시 시 백분율 변환.
- 연도별 행, 영구 유지(w=1), 매년 10% 감소(w=0.9), 매년 20% 감소(w=0.8) 열로 결과를 표시한다. 범위·대표값으로 합치지 않는다.
- 초과이익 = 자기자본 × (예상 ROE - 요구수익률).
- 주당 가치 = (자기자본 + 초과이익 × w / (1 + 요구수익률 - w)) / 총 주식수.
- 각 연도는 독립 시나리오다. ROE 계산용 평균 자본은 S-RIM 공통 자기자본을 변경하지 않는다.
- 리포트에 입력값, 연도별 계산 근거, 기준일, 계산 결과를 보존한다. 최신 데이터로 자동 덮어쓰지 않는다.
- 비교 주가는 기준일을 명시하고 저장 당시 가격과 현재 가격을 혼동하지 않게 한다.

## 기존 구조 조사
- ValuationParams는 JSON으로 저장되며 discountRate는 기존 DCF 계산에서 사용한다. S-RIM 요구수익률은 별도 필드로 분리한다.
- ReportSnapshot은 재무 원시 데이터 스냅샷을 보존한다.
- ReportValuation의 기존 청산가치·DCF는 조회 시 파생 계산한다. S-RIM 결과 보존 요구와 구분하여 설계한다.
- 기존 기업 리포트는 국내·미국을 지원한다. 자동 입력은 지배주주지분과 정확한 주식수 출처를 확인한 경우만 사용하며 자본총계를 무조건 대체하지 않는다.
