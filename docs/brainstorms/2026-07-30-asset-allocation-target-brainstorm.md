**Date:** 2026-07-30

## 배경

- 태형님 요청: "전체 금액 비율을 지정하고 해당 비율대로 투자하는 식으로 가고 싶다. 안전자산/투자자산이 있고 투자자산이 수익이 나서 비율이 넘어가면 얼마가 넘어갔고 퍼센트는 얼마인지 보여주고, 투자자산 내에서도 금·주식 등 자산군별 비율이 있도록"
- 기존 구조 (이미 있는 것):
  - `PortfolioItem` + `AssetType` 9종: STOCK(주식), BOND(채권), REAL_ESTATE(부동산), FUND(펀드), CRYPTO(암호화폐), GOLD(금), COMMODITY(원자재), CASH(현금성), OTHER(기타)
  - 평가액 계산: `PortfolioEvaluationService` — STOCK은 현재가 기준 실시간 평가, 나머지는 투자원금을 평가액으로 사용 (`PortfolioEvaluationService.java:65`)
  - 포트폴리오 페이지: `partials/portfolio.html` + `js/components/portfolio.js`
- 문제: 자산군 정보는 있으나 목표 배분(안전 vs 투자, 투자 내 자산군별)을 설정하고 현재 배분과 비교·경고하는 기능이 없음

## What We're Building

1. **목표 배분 설정**: 상위 2버킷(안전자산/투자자산) 목표 비율(예: 30:70) + 투자자산 내부 자산군별 목표 비율 설정
2. **현재 배분 계산**: 평가액 기준으로 실제 비율 산출 (ACTIVE 항목만)
3. **편차 표시**: 버킷·자산군별로 목표 대비 편차를 **금액(원)과 %p** 두 가지로 표시 — 편차 금액이 곧 리밸런싱 필요 금액
4. **허용밴드 경고**: 편차가 허용밴드(기본 ±5%p, 조정 가능)를 벗어나면 경고 색상으로 강조

## 확정된 결정 (태형님 선택, 2026-07-30)

| 항목 | 결정 |
|------|------|
| 안전/투자 분류 | **AssetType 고정 매핑** — CASH·BOND=안전자산, STOCK·FUND·CRYPTO·GOLD·COMMODITY·REAL_ESTATE·OTHER=투자자산 (사용자 재정의 없음) |
| 비율 계산 기준 | **평가액 기준** — 기존 `PortfolioEvaluationService` 재사용 (STOCK은 현재가, 나머지는 원금) |
| 초과 강조 기준 | **허용밴드 초과 시 강조** — 편차는 항상 표시, 밴드(기본 ±5%p, 사용자 조정 가능) 초과 시에만 경고 강조 |
| 세부 비율 범위 | **투자자산 내부만** — 자산군(AssetType)별 목표 비율. 안전자산은 상위 비율만 |

## 구현 방향

- **신규 Entity**: 사용자별 목표 배분 설정 1건 — 상위 안전/투자 목표 비율, 투자자산 내 AssetType별 목표 비율, 허용밴드(%p)
  - Entity 생성은 Approval Gate 대상 → plan 단계에서 상세 설계 후 승인받고 진행
- **API**: 목표 배분 설정 조회/저장 + 현재 배분 현황 조회(목표·현재·편차·밴드초과 여부를 계산해 반환)
- **UI**: 포트폴리오 페이지에 "자산 배분" 섹션 — 목표 vs 현재 비율, 편차 금액·%p, 밴드 초과 시 경고 강조, 목표 설정 모달

## 검토한 대안 (채택 안 함)

- **유형 기본 매핑 + 사용자 재정의** — 유연하지만 설정 화면·저장 구조가 늘어남. 고정 매핑으로 단순화 (태형님 선택)
- **항목별 개별 안전/투자 지정** — 가장 유연하나 항목마다 설정 필요, 과한 복잡도
- **투자원금 기준 비율** — "수익이 나서 비율이 넘어가는" 상황을 잡지 못함 → 평가액 기준 채택
- **안전자산 내부 세부 비율** — 요청 범위 밖, 필요 시 후속 작업

## Edge Cases

- 목표 미설정 사용자 → 배분 섹션에 설정 유도만 표시, 경고 없음
- 비율 합 검증: 상위(안전+투자)=100%, 투자 내 자산군 합=100% — 저장 시 검증
- 포트폴리오 비었거나 총 평가액 0 → 현재 비율 계산 불가, 표시 생략
- 주식 현재가 조회 실패 → 원금 기준 평가(기존 fallback 동작 그대로)
- 목표에 비중 0%로 둔(또는 미지정) 자산군을 보유 중 → 목표 0% 취급, 보유 평가액 전액이 초과분
- CLOSED 항목 제외 (ACTIVE만 집계)

## 범위 밖 (하지 않음)

- 자동 리밸런싱 실행(매수/매도 주문·이체) — 표시만 제공
- 메일/푸시 알림 — 화면 표시만
- 안전자산 내부 자산군별 비율
- AssetType 매핑 사용자 재정의
- 기존 평가 로직(`PortfolioEvaluationService`) 변경
