## What We're Building

정량 5항목(자산 저평가·수익 저평가·재무건전성·수익성·성장성)에 대해 **스냅샷 + 가치평가 값으로 제안 등급(A~E)과 근거를 자동 산출**해 위저드 7단계와 상세 뷰에 표시한다. 최종 등급은 지금처럼 태형님이 select로 확정한다(오버라이드). 정성 2항목(사업역량·주주중시)은 제안하지 않는다.

## 등급 기준 (태형님 승인 기준표, 2026-07-24 대화)

공통: A는 "그 항목 하나로 매수 근거가 되는 수준"의 절대평가. 두 신호(예: 청산가치·PBR)가 있으면 **유리한 쪽 밴드**를 취한다.

### ① assetUndervalue — 시가총액/청산가치(파생), PBR(스냅샷)
- 청산가치 밴드: A ≤1.0배 / B ≤1.5배 / C ≤2.5배 / D ≤4.0배 / E 초과
- PBR 밴드: B ≤0.6 / C ≤1.0 / D ≤2.0 / E 초과 (자산 A는 청산가치 근거일 때만)
- 둘 다 없으면 제안 없음

### ② earningsUndervalue — 시총/DCF보수·낙관(파생), PER(스냅샷)
- DCF 밴드: A 보수≤1.0배 / B 보수≤1.5배 / C 낙관≤1.0배 / D 낙관≤1.5배 / E 초과
- PER 밴드: B ≤8 / C ≤15 / D ≤25 / E 초과
- FCF ≤ 0(DCF 계산 불가)이고 PER도 없으면(적자) → E
- 근거가 전혀 없으면 제안 없음

### ③ financialHealth — 건전성 판정 3종 + 위험 시그널 + 순현금
- E: risk 2개 이상 또는 채무초과(negativeEquity)
- D: risk 1개
- C: warn 있음(판정 결손도 warn으로 보수 처리)
- B: 자기자본비율·유동비율·부채비율 모두 good
- A: B 조건 + 순현금(netCash) > 0 + 위험 시그널 전부 false (유상증자 이력은 제외 — 건전성이 아닌 주주정책 성격)
- 판정 3종 모두 없으면 제안 없음

### ④ profitability — 수익성 판정 3종 + 다년 값
- E: 영업이익률 risk(≤0, 영업적자) 또는 기준연도 ROE < 0(순적자)
- D: risk 있음
- C: warn 있음(결손 포함)
- B: 영업이익률·ROE·ROA 모두 good
- A: B 조건 + ROE ≥ 15% 그리고 영업이익률 ≥ 10%가 기준연도 포함 최근 3개 연도(최소 2개 연도 존재) 지속
- 판정 3종 모두 없으면 제안 없음

### ⑤ growth — 매출·영업이익 성장률(기준연도 + 추세)
- 기준연도 두 성장률 중 하나라도 없으면 제안 없음
- E: 둘 다 음수가 2년 연속(기준연도+직전연도)
- D: 한쪽이라도 음수 (둘 다 음수 단년 포함)
- C: 둘 다 0 이상
- B: 둘 다 ≥ 10%
- A: B 조건 + 최근 4개 연도 중 3개 연도 이상 둘 다 ≥ 10%

## Edge Cases

- 청산가치 ≤ 0 → 비율 null(기존 계산기 동작) → PBR 밴드만으로 판정.
- 자본잠식 → ROE 시리즈 자체가 제외됨(분모>0 조건) → 수익성은 남은 판정으로, E 조건은 영업이익률 risk로 포착.
- 성장률 기저효과(전년 적자 등) → 전년 0/결손 시 성장률이 없으므로 제안 생략 — 오판보다 생략.
- 구 스냅샷(schemaVersion 1) 그대로 동작 — 제안은 조회 시 계산이라 스냅샷 마이그레이션 불필요.
- 프론트: `suggestedGrades` 없거나 항목 없으면 아무것도 표시하지 않음(하위 호환).

## 범위 밖 (하지 않음)

- 정성 2항목(사업역량·주주중시) 자동 제안.
- 제안값 저장·이력 관리(확정값과의 차이 추적).
- 등급 select 자동 채움(제안이 있어도 [적용] 클릭 전에는 폼 값 불변).
- 기준치 파라미터화(리포트별 임계값 조정) — 후속 후보.
